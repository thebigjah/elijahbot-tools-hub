IV.The recognition keys

If you skip everything else, get THESE right and the character will read as Elijah:

  • Multi-tonal hair — use all four hair hex codes, not just one. The sun-bleached top + ginger flecks are what differentiate from generic warm-blonde characters.
  • Blue-grey eyes — #9BB5C2, NOT brown. Default voxel character defaults to dark/warm — you'll have to override.
  • Lighter facial hair than head hair — strawberry/peach for beard, deeper brown for head. Distinct palettes.
  • Shoulder-length hair drape — not buzzed, not short. It should fall past the head bottom on the sides and back.
  • Brass chest plate — sets the bot identity. Don't dress him in clothes; go straight to plate.
Procedural geometry can't fake likeness. This sheet exists because the in-browser Voxel Studio I built reads as "generic shapes that add up," not as a person. The only path to a recognizable @elijahbot character is a human (you) at the keys in MagicaVoxel using these anchors as a guide. The .vox export from pv-social.vercel.app/voxel-studio gives you a starting bust skeleton you can refine against this reference.

V.Ten emotional variants to build

Once the base model is locked, clone it ten times and change ONE thing per variant. Keep everything else identical so they read as the same character across states.

  • Neutral — default expression. Eyebrows flat, lips neutral.
  • Smiling — lip row shifts up at corners (x=22, x=26 move up 1 voxel).
  • Concerned — eyebrows angle down toward nose bridge.
  • Surprised — eyebrows lift 1 voxel; mouth opens (replace with darker void).
  • Sleeping — eye voxels become skin tone (eyes closed); slight head tilt.
  • Studying — eyebrows furrow inward; small glasses overlay (2-voxel rims).
  • Praying — eyes closed, slight upward gaze (head tilt 1 voxel up).
  • Thinking — one eyebrow lifted 1 voxel.
  • Disappointed — mouth corners down 1 voxel; brows flat.
  • Laughing — eyes squint (single voxel each); mouth wide open.

VI.Workflow

  • Open Voxel Studio → click .vox → download the bust skeleton.
  • Open MagicaVoxel → import the .vox → it lands as the procedural bust.
  • Print this reference sheet (browser → print) and place beside the monitor.
  • Refine eyes / facial hair / hair multi-tone using the anchor table.
  • Save base as elijahbot_neutral.vox.
  • Clone and modify per variant table. Save each as elijahbot_<state>.vox.
  • Export PNGs (front + side + 3/4 for each variant) for IG content.
